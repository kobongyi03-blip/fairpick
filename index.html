    04사용 방법 & 랜덤 추첨 공정성 안내

    공정추첨기는 어떻게 사용하나요?

    1) 명단 칸에 참여자 아이디나 이름을 붙여넣으세요. 줄바꿈, 쉼표, 띄어쓰기 모두 구분자로 인식합니다. 댓글을 복사해 온 경우에는 위쪽 [댓글 텍스트에서 아이디만 추출] 버튼을 쓰면 더 편합니다.

    2) 당첨 인원을 정한 뒤, 룰렛 돌리기 또는 카드 즉시 추첨 중 원하는 방식으로 추첨 시작을 누르면 됩니다.

    3) 추첨이 끝나면 공정 추첨 인증서가 발급됩니다. 결과 텍스트 복사 버튼으로 블로그나 인스타그램 공지글에 바로 붙여넣을 수 있어요.

    댓글에서 아이디만 추출하는 기능은 어떻게 동작하나요?

    인스타그램, 블로그, 유튜브 댓글을 드래그해 통째로 붙여넣으면, 각 줄의 첫 단어가 아이디 형태(@포함 가능)인 경우에만 명단에 넣습니다. "3시간 전", "2일 전" 같은 시간 표시, "좋아요 2개" 같은 반응 수, 날짜, "답글 달기"·"번역 보기" 같은 버튼 문구는 자동으로 걸러집니다.

    아이디와 댓글 내용이 한 줄에 같이 있는 경우에도 첫 아이디만 뽑아냅니다. 추출이 끝나면 같은 아이디는 한 번만 남기고 정리해서 명단 칸에 넣어 드립니다.

    추첨이 정말 공정한가요? 난수는 어떻게 만드나요?

    일반적인 Math.random()은 예측 가능한 의사난수라 추첨용으로는 한계가 있습니다. FairPick은 브라우저에 내장된 암호화 난수 생성기 window.crypto.getRandomValues()만 사용합니다. 운영체제의 엔트로피를 기반으로 만들어져 예측이 사실상 불가능합니다.

    또한 범위 나눗셈에서 생기는 미세한 쏠림(모듈로 편향)을 막기 위해, 범위를 벗어나는 난수는 버리고 다시 뽑는 거부 표본 방식을 씁니다. 모든 참여자가 정확히 같은 확률을 가집니다.

    중복 참여는 어떻게 처리되나요?

    중복 참여자 자동 제거가 켜져 있으면 같은 아이디가 여러 번 입력돼도 1명으로 계산하고, 제거된 건수를 화면에 표시합니다. 댓글을 여러 개 단 사람이 당첨 확률을 높이는 일을 막을 수 있어요. 이벤트 규칙상 중복 응모를 인정한다면 토글을 끄면 됩니다.

    중복을 허용한 상태에서 [당첨자 제외하고 다시 뽑기]를 누르면, 당첨된 이름 전체가 아니라 당첨된 표 1건씩만 명단에서 빠집니다.

    공정 추첨 인증서는 무엇인가요?

    추첨이 끝날 때마다 당첨자 목록, 추첨 일시, 총 응모자 수, 중복 제외 수, 그리고 검증 코드를 담은 인증서가 발급됩니다. 검증 코드는 추첨 일시·전체 명단·당첨자 목록·솔트 난수를 SHA-256으로 해싱한 값이라, 명단이나 결과가 바뀌면 코드도 달라집니다.

    [인증서 이미지(PNG) 저장] 버튼을 누르면 인증서를 이미지 파일(FairPick_추첨인증서.png)로 내려받을 수 있어, 당첨자 발표 글에 그대로 첨부할 수 있습니다.

    참여자가 아주 많으면 어떻게 되나요?

    룰렛은 참여자가 30명 이상이면 칸 글자를 자동으로 작게 줄여 겹침을 막고, 40명을 넘으면 칸 안의 이름을 생략하는 대신 [카드 즉시 추첨]을 추천하는 안내가 표시됩니다. 참여자가 많을수록 카드 방식이 결과를 확인하기 편합니다.

    10,000회 공정성 테스트는 뭔가요?

    현재 명단 그대로 10,000번 가상 추첨을 실행해 참여자별 당첨 비율을 막대그래프로 보여주는 기능입니다. 참여자가 10명이면 모두 10% 안팎으로 나와야 정상입니다. 특정인에게 쏠리는 결과가 나오지 않는 것을 직접 눈으로 확인할 수 있습니다.

    입력한 명단이 서버로 전송되나요?

    아니요. 명단 입력부터 댓글 추출, 추첨, 인증서 발급까지 전부 사용 중인 브라우저 안에서만 처리됩니다. 명단이 외부 서버로 전송되거나 저장되지 않으니, 팔로워 아이디를 안심하고 붙여넣으셔도 됩니다.
